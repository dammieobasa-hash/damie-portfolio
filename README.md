# Damie Obasa Portfolio

A clean, modern personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- index.html — all portfolio content
- style.css — colors, layout, spacing and design
- script.js — small JavaScript interaction

## Editing the portfolio

Open the folder in VS Code.

### Change text
Open `index.html`.

### Change the design
Open `style.css`.

You can change:
- colors
- fonts
- spacing
- card sizes
- backgrounds
- button styles

### Add JavaScript
Open `script.js`.

## Running it

You can double-click `index.html` to open it in your browser.

Or install the Live Server extension in VS Code, then:
Right-click `index.html` → Open with Live Server.
